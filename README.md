# Warehouse-Robot-Pathfinding
A C++ project that finds efficient paths for warehouse robots using A* Search, DFS, and Queue data structures
# About

A simple project that simulates a warehouse robot finding a path to collect products and deliver them to a packing station while avoiding obstacles.

# Features

- Find the shortest path to the destination
- Avoid obstacles like shelves and boxes
- Use A* Search to find an efficient path
- Use DFS to explore warehouse areas
- Manage pickup and delivery tasks using a Queue
- Display the robot's path on a grid

# Technologies

- C++
- Data Structures and Algorithms
- A* Search Algorithm
- Depth-First Search (DFS)
- Queue and Graphs

# How to Use

1. Download or clone the project repository.
2. Open the code in any C++ IDE or compiler.
3. Compile and run the program.
4. Enter the starting point and destination.
5. Add obstacles to the warehouse grid.
6. View the path found by the robot.
